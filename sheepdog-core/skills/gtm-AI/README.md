# GTM-AI Skill

Powerful AI-driven Google Tag Manager automation and optimization skill.

## Overview

GTM-AI is an advanced skill that automates Google Tag Manager operations including:

- **Tag Deployment**: Create, update, and manage tags at scale
- **Container Auditing**: Analyze and validate GTM configurations
- **Tracking Implementation**: Deploy event tracking across websites
- **Trigger Management**: Configure and optimize trigger conditions
- **Variable Setup**: Define and manage data layer variables
- **Version Control**: Manage container versions and rollbacks

## Quick Start

### Installation

```bash
cd gtm-ai
npm install
```

### Configuration

Create `.env` file with:

```
GOOGLE_ACCOUNT_ID=12345678
GOOGLE_CONTAINER_ID=GTM-XXXXXX
GOOGLE_WORKSPACE_ID=workspace-id
GOOGLE_CREDENTIALS_PATH=./credentials.json
```

### Basic Usage

```
Use GTM-AI to:
- Audit the current GTM container
- Create GA4 event tags
- Set up form tracking
- Implement scroll tracking
```

## Key Operations

### Audit Container

Analyzes the current GTM container and identifies:
- Unused variables
- Duplicate triggers
- Configuration inconsistencies
- Performance issues

### Deploy Tags

Creates and configures tags based on:
- Event type requirements
- Conversion tracking needs
- GA4 specifications
- Custom parameters

### Manage Triggers

Sets up triggers for:
- Page views
- Events
- Form submissions
- Clicks and interactions

## Templates

Includes ready-to-use templates for:
- GA4 Event Implementation
- Facebook Pixel Tracking
- LinkedIn Insight Tag
- Form Tracking
- E-commerce Tracking
