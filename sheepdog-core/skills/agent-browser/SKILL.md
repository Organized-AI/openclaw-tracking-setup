# Agent Browser Skill

Automated browser interaction and web testing skill for Claude Code.

## Overview

The agent-browser skill provides automated browser control using Playwright for:

- Form filling and submission
- Navigation and clicking
- Screenshot capture
- Data extraction
- Visual testing
- Interaction automation

## Key Features

- **Smart Element Detection**: Find elements by text, role, or CSS selectors
- **Form Automation**: Fill and submit forms intelligently
- **Screenshot Capture**: Save visual evidence of actions
- **Data Extraction**: Get structured data from pages
- **Error Recovery**: Handle common browser scenarios
- **Mobile Support**: Test responsive designs

## Usage in Prompts

```
Use the agent-browser skill to:
- Navigate to [URL]
- Fill the form with [data]
- Capture screenshots
- Extract table data
```

## Capabilities

- Page navigation
- Element interaction (click, type, hover)
- Form handling
- Screenshot capture
- JavaScript execution
- Cookie and session management
- Error handling and retries
